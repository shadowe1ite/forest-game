# The Last Signal

The Last Signal is a complete 2D top-down pixel-art forest adventure built with **HTML5 Canvas + vanilla JavaScript**.

You wake up lost in a hostile forest and must recover three missing radio components, repair the abandoned tower, and escape.

## Play locally

1. Open `/home/runner/work/forest-game/forest-game/index.html` in any modern browser.
2. Click **Start Adventure**.

(Any static host, including Cloudflare Pages, can deploy these files directly.)

## Controls

- **WASD** or **Arrow Keys**: Move
- Avoid wandering creatures (they chase when close)
- Collect all 3 radio components
- Reach the radio tower after collecting all components

## Gameplay loop

- Explore a retro forest with grass, flowers, bushes, rocks, paths, and water.
- Gather parts shown in the objective tracker and inventory.
- Keep your health above 0 while avoiding creature attacks.
- Win by activating the tower with all radio parts.
- Lose when health reaches 0, then use **Restart**.
